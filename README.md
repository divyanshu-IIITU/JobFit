# JobFit

JobFit is a resume-to-job-description matching application. A user uploads a PDF resume, pastes a job description, and receives suggestions generated by Google Gemini.

## How it works

1. The React form accepts one PDF resume and a job description.
2. The Next.js PDF endpoint saves the upload temporarily.
3. `process_resume.py` extracts text from the PDF with PyPDF2.
4. The extracted resume text and job description are sent to Gemini.
5. The generated match and suggestions are displayed in the browser.

## Project structure

```text
Jobfit/
├── src/app/page.tsx                 Homepage
├── src/app/components/UploadForm.tsx Upload and matching UI
├── src/app/api/extract-pdf/route.ts  PDF extraction endpoint
├── src/app/api/match/route.ts        Gemini matching endpoint
├── process_resume.py                 PDF text extraction
├── requirements.txt                  Python dependencies
├── public/                           Static assets
└── .env.local                        Local secrets; do not commit
```

## Requirements

- Node.js and npm
- Python 3.10 or newer
- A Google Gemini API key

## Setup on Windows

From PowerShell, run:

```powershell
cd D:\Jobfit
.\.venv\Scripts\Activate.ps1
npm install
python -m pip install -r requirements.txt
```

If the virtual environment does not exist, create it first:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

If Python is not available on `PATH`, set its full path in `.env.local`:

```env
PYTHON_BIN=C:\Path\To\python.exe
```

## Run locally

Start the development server:

```powershell
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```powershell
npm run build
npm run start
```

The application must run on a host that supports the Node.js server, Python, and PyPDF2. The PDF endpoint starts a local Python process, so serverless hosts without Python support may require a separate PDF extraction service.

## Validation and maintenance

```powershell
npm run lint
npm run build
```

Keep the Gemini API key private. Uploaded resumes may contain personal information and are sent to the configured Gemini API for analysis.
